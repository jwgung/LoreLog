# LoreLog

**내 안드로이드에서 내 하루를 텍스트로 모아, 나에 관한 개인 지식그래프의 재료로 내보내는 라이프로그 앱.**

개인용 · 로컬 암호화 저장 · 폰은 수집만 · 전사·요약은 내 서랍에서(내가 고른 모델)

[**APK · 데스크톱 앱 다운로드**](https://github.com/jwgung/LoreLog/releases/latest) · [릴리스](https://github.com/jwgung/LoreLog/releases)

[English](README.md) · 한국어

---

폰은 늘 곁에 있는 센서다. LoreLog는 "폰에서 일어나는 일 + 폰이 곁에서 본 일상"(음성·앱 사용·화면 내용·위치·알림·통화/문자·일정)을 하나의 시간순 타임라인으로 모은다. 모은 기록은 기기에만 암호화해 두고, 원할 때 JSON·파일·HTTP로 내보내 개인 지식그래프(*your lore*)에 붙인다.

> ⚠️ **개인용 도구다.** 본인 기기에서 본인 데이터만 수집하도록 만들어졌다. 다른 사람을 몰래 감시하는 용도가 아니며, 그렇게 쓰면 안 된다.

## 처음 쓰기

설치부터 첫 대화까지 이 순서로 간다. 데스크톱 앱은 처음 켤 때 2~6단계를 직접 안내한다(**처음 설정**. 아무 단계나 건너뛸 수 있고, 나중에 설정 → "처음 설정 안내 다시 열기"로 다시 연다).

1. **설치.** [릴리스](https://github.com/jwgung/LoreLog/releases/latest)에서 OS에 맞는 데스크톱 앱과 안드로이드 APK를 받는다. 파일과 처음 켤 때의 경고는 [데스크톱 앱](#데스크톱-앱-windows--macos--linux)과 [설치 & 설정](#설치--설정)에 있다.
2. **서랍.** 처음 켤 때 **이 PC에 두기**를 고른다. 앱이 서랍을 돌리고, 기록·메일과 일정 노트·검색 색인이 모두 이 PC에 남는다.
3. **모델.** 비서와 사서는 내가 고른 모델(OpenAI 호환 주소)에게 묻는다. 기본 모델은 없고 내 기록이 그 주소로 가므로, 내 PC나 믿는 서버만 넣는다. 예:
   - [Ollama](https://ollama.com): `http://127.0.0.1:11434/v1`, 모델 `qwen3:8b`(먼저 `ollama pull qwen3:8b`). 긴 메일이 들어가도록 Ollama에 `OLLAMA_CONTEXT_LENGTH=8192`를, 서랍이 다른 기계에서 부르면 `OLLAMA_HOST=0.0.0.0`도 주고 Ollama를 다시 켠다.
   - [LM Studio](https://lmstudio.ai): Developer에서 서버를 켜면 `http://127.0.0.1:1234/v1`. 모델 이름은 LM Studio에 보이는 그대로.

   **연결 확인**을 누르면 앱이 모델에게 짧게 물어보고, 답이 없으면 무엇을 고칠지 알려 준다.
   > **작은 모델을 CPU로**(8B 안팎) 돌리면 대화와 검색은 쓸 만하지만 관계 그래프는 너무 느리다. 메일 한 건에 4분쯤 걸리고 남는 관계도 적다. 그래프까지 쓰려면 GPU가 있는 PC나 서버의 모델을 쓴다.
4. **메일과 일정.** IMAP 계정(읽기만. 2단계 인증을 쓰는 곳은 앱 비밀번호)과 CalDAV 달력. 설정과 같은 양식이다.
5. **폰.** PC와 폰에 [Tailscale](https://tailscale.com/download)을 설치하고 같은 계정으로 로그인한다. 안내의 폰 단계에서 **연결 코드 보기**를 누르면 한 줄 `lorelog://connect?…`와 복사 버튼, QR이 나온다. 폰에서 서랍 → 수집·연동 설정 → **서랍 연결**의 **연결 코드 붙여 넣기**에 넣고 **코드로 채우고 저장**을 누른다. 폰도 처음 켤 때 이것을 묻는다. **코드에는 서랍의 토큰이 들어 있다.** 코드를 가진 사람은 서랍을 읽고 쓸 수 있으니 내 폰에만 넣는다. 폰은 손으로 넣은 주소와 마찬가지로 https나 tailnet 주소일 때만 받는다.
6. **첫 동기화.** 마지막 단계에서 동기화를 본다: 색인한 기록 수, 그래프가 읽은 메일과 기다리는 메일. 1시간마다 이어서 하고, 끝나기 전에도 대화할 수 있다.

## 원칙

- **본인 기기, 본인 데이터만.** 제3자 감시·은닉 수집이 아니다.
- **드러낸다.** 모든 수집은 OS 표준 권한 동의와 **상시 알림**으로 보인다. 숨기지 않는다. 기록 중일 때만 수집한다.
- **로컬 암호화 저장.** 기록은 기기 안 SQLCipher 암호화 DB에, 서랍 토큰은 Keystore 기반 저장소에 둔다. 이 앱이 클라우드에 저장하는 것은 없다.
- **폰은 수집만 한다. 처리는 내 서랍에서, 내가 고른 모델로.** 폰은 전사도 요약도 하지 않는다. 말소리는 **서랍**(내 서버나 데스크톱의 LoreLog)로 보내 서랍에 설정한 음성 모델이 전사하고, 요약·정리도 서랍이 내가 고른 모델로 한다. 폰이 기록이나 말소리를 Google 등 클라우드로 보내는 일은 없다. 서랍에 닿지 않으면 기록과 음성은 폰에 쌓였다가 닿을 때 보낸다. 노출은 최소화하고(VAD로 말할 때만 녹음), 서랍 주소·토큰은 사용자가 정한다. 본체는 텍스트고, 오디오는 "무슨 소리였는지" 다시 들어볼 수 있게 AAC로 잠시만 보관한다(내보낸 뒤 즉시, 내보내지 않으면 7일 뒤 삭제. 내보내기에는 포함되지 않는다).

## 수집하는 것

전부 같은 포그라운드 서비스에서 돌고, 설정에서 항목별로 켜고 끈다.

| 종류 | 출처 | 비고 |
|---|---|---|
| **음성** | 녹음 → 서랍으로 보내 전사 | Silero VAD(신경망)로 **말할 때만** 캡처. 화면 꺼져도 유지. 텍스트만 저장 |
| **앱 사용** | UsageStatsManager | 어떤 앱을 언제 썼나 |
| **화면 내용** | AccessibilityService | 앱 안에서 본 텍스트. 은행·결제 등 **민감 앱 제외** |
| **위치** | FusedLocationProvider | 5분 간격·저전력·배치 |
| **알림** | NotificationListenerService | 받은 알림 제목·본문 |
| **통화·문자** | CallLog · SMS · 연락처 | 누구와 언제(번호→이름 매칭) |
| **캘린더** | CalendarContract (+참석자) | 폰의 모든 캘린더(로컬 포함). 1년 전부터 1년 뒤까지 등록된 일정 전부(제목·시간·장소·메모·참석자 주소)를 `calendar_event` 줄로 서랍에 보내고, 바뀌면 다시, 지우면 `deleted`로 한 번 보낸다. 서랍은 이것을 일정으로 색인한다(CalDAV로도 들어온 같은 일정은 한 번). 캘린더 앱에서 숨긴 캘린더와 취소된 일정은 빼고, 수집 항목에서 끄면 보냈던 일정을 지운 것으로 한 번 보내 서랍에서도 빠진다 |
| **주소록** | ContactsContract | 주소록이 가진 것은 다(이름·별명·메일·전화·회사·직함·주소·웹사이트·메모·생일·기념일·관계·메신저·그룹, CardDAV와 같은 모양). 사진만 뺀다. 바뀌었을 때만 목록 전체를 서랍의 `/ingest/contacts`로. 사서가 사람을 알아보는 데 쓴다. https나 tailnet 주소로만 보낸다. 수집 항목에서 끄면 빈 목록을 한 번 보내 서랍에서도 빠진다 |

## 음성

LoreLog의 핵심이자 가장 까다로운 부분. 구글 실시간 인식기는 오디오 포커스를 계속 뺏어(미디어 끊김) 상시 수집에 안 맞아, **녹음 기반**으로 설계했다.

- **마이크 양보** — 안드로이드는 마이크를 한 앱만 쓰게 한다. 음성 녹음·카메라 앱이 맨 앞에 오거나(사용 정보 접근 권한 필요) 통화 중이거나(일반·VoIP) 다른 앱이 실제로 녹음을 시작하면 마이크를 놓고, 끝나면 자동으로 다시 연다. 목록에 없는 앱은 알림의 "마이크 10분 양보"나 화면 버튼으로 수동 양보한다.
- **VAD 캡처** — `AudioRecord`로 원본 PCM을 받아 **Silero VAD**(작은 신경망, ONNX)로 사람 말이 있을 때만 구간을 모은다. 키보드·식기·에어컨 소리에는 깨어나지 않고, 말소리 합이 3초 미만인 배치는 버린다. 32ms 프레임당 추론 1ms 안쪽이라 부하가 거의 없다. 오디오 포커스를 뺏지 않아 미디어가 안 끊긴다.
- **전사는 서랍이 한다** — 폰은 말 구간을 WAV로 묶어 서랍의 `/transcribe`로 보내고, 서랍이 사용자가 고른 음성 모델(`LIFE_ASR_URL`·`LIFE_ASR_MODEL`, 데스크톱은 설정 화면)로 넘긴다. 폰에는 전사 엔진도 API 키도 없다. 가까운 발화는 ~4분으로 묶어 보낸다(대화가 3분 넘게 끊기면 그때까지 모인 것으로 마감). 요청 수가 줄고 짧은 토막보다 정확도도 낫다.
- **서랍에 닿지 않으면 보관 후 전송** — 서랍 주소가 없거나 닿지 않으면 말 구간을 음성파일로 앱 폴더에 쌓아 두고, 닿으면 **자동(주기 워커) 또는 수동("밀린 음성 전사")**으로 보낸다. 녹음·보관은 상관없이 이어진다.
- **말하기(받아쓰기)** — 대화 화면의 "말하기"도 서랍의 `/transcribe`로 받아 적는다. 녹음 파일은 받아 적은 뒤 바로 지운다.
- **블루투스 이어폰 마이크(선택)** — 녹음 입력을 BT 헤드셋 마이크로 돌린다.
- **통화 녹음 가져오기** — 라이브 통화 음성은 OS가 막는다. 대신 전화앱이 저장한 통화 녹음 폴더를 지정(SAF)하면 그 파일을 서랍으로 보내 전사한다(삼성 등 내장 녹음 기종). 서랍에 닿지 않으면 다음 확인 때 다시 보낸다.

## 대화

- **대화 묶기** — 음성 조각을 시간 간격으로 묶어 "대화" 단위로 만들고, 겹치는 통화(연락처)·회의(캘린더 참석자)로 참석자를 자동 연결한다. 애매하면 **검토 큐**("태그할 대화")에 올린다. 큐에는 그 대화의 전사 내용 일부와 ▶ 듣기 버튼이 같이 보여 누구였는지 확인한 뒤 적거나 "넘기기"로 닫을 수 있다.
- **요약은 폰에서 하지 않는다** — 원본을 충실히 서랍으로 넘기고, 하루 정리·요약은 서랍이 사용자가 고른 모델로 한다(스키마가 바뀌면 다시 정리할 수 있다).

## 내보내기 / 삭제

- **JSON** — 전체 기록을 공유 시트로.
- **폴더(증분 NDJSON)** — 새 기록만 앱 전용 외부 폴더에 append. `Android/data/com.lorelog/files/exports/`. USB·adb로 PC에서 접근.
- **서랍으로 전송(HTTP)** — 서랍 주소로 새 기록을 15분마다 POST(`Authorization: Bearer <토큰>`, NDJSON). 설정 → 서랍 연결의 **"와이파이에 연결됐을 때만 보내기"**를 켜면 기록과 음성(녹음·통화 녹음)의 자동 전송을 와이파이(데이터 요금 없는 망)에서만 하고, 그동안은 폰에 쌓인다(기본 꺼짐). 폰 캘린더도 기록과 함께 보내며 같은 설정을 따른다. "지금 전송", "밀린 음성 전사", 말하기는 바로 보낸다.
- 모든 줄에 `type`(voice/app/screen/location/notification/comm/calendar/calendar_event/conversation)이 붙는다.
- **전체 삭제** — 확인 후 모든 기록 삭제(되돌릴 수 없음).

## 저장 · 보안 · 보존

- **암호화** — DB는 SQLCipher로 암호화. 키는 랜덤 32바이트를 Android Keystore가 보호하는 `EncryptedSharedPreferences`에 보관(기기를 벗어나지 않음). 서랍 토큰도 같은 방식으로 암호화 저장하며 커밋하지 않는다.
- **보존** — 기기엔 최근 **30일**만. 이미 내보냈고 30일 지난 원본은 자동 삭제(대화는 유지). 장기 보관은 내보낸 지식그래프 쪽이 맡는다.
- **음성 오디오** — 전사된 조각의 오디오는 `Android/data/com.lorelog/files/voice_kept/`에 AAC(약 0.35MB/분)로 보관되고 타임라인에서 **▶ 듣기**로 재생할 수 있다. 폴더/HTTP 내보내기에 포함된 조각의 오디오는 그 즉시, 내보내지 않은 것은 **7일** 뒤 지운다. 전사 대기 중인 파일도 타임라인에 "전사 대기"로 보이고 바로 들을 수 있다. 재생 중에도 캡처는 계속된다. 에코 캔슬러(AEC)로 재생 소리를 마이크 입력에서 빼고, 그래도 잡힌 묶음은 "재생 중" 라벨이 붙으며, 전사 결과가 재생한 텍스트와 같으면 버린다(대화가 섞였으면 남긴다).
- **알림/표시** — 상시 알림은 지워도 복귀(항상 유지). 설정에서 알림 숨기기(멈춤 알림 숨김 + 기록 알림 최소화)와 백그라운드 "감시중" 플로팅 배지(오버레이)를 켤 수 있다.
- 주의: 내보낸 파일과 서랍으로 보내는 본문(기록·음성)은 앱이 따로 암호화하지 않는다. 서랍 주소는 HTTPS나 tailnet으로 두고, 폴더 접근은 직접 관리한다.

## 설치 & 설정

1. [릴리스](https://github.com/jwgung/LoreLog/releases/latest)에서 APK(`LoreLog-<버전>.apk`)를 받아 설치한다.
2. **Play 프로텍트 경고**: 권한이 많아 사이드로드 시 경고가 뜬다. 코드로 없앨 수 없으니, 쓰려면 Play 스토어 → Play 프로텍트 검사 끄기(또는 "검사 없이 설치"), 삼성은 Auto Blocker 끄기.
3. 앱에서 **기록 시작** → 뜨는 권한을 허용한다(마이크만 허용해도 시작된다).
4. 서랍 → 수집·연동 설정 → **서랍 연결**에 데스크톱 앱의 연결 코드를 **연결 코드 붙여 넣기**에 넣거나([처음 쓰기](#처음-쓰기)), 서랍 주소(예: `https://<서랍>/ingest/lorelog`)와 토큰을 넣고 저장한다. 토큰은 https나 tailnet(`*.ts.net`, `100.x`)·이 기기 주소로만 보낸다. 음성 전사·말하기·일기가 같은 주소와 토큰을 쓴다. 주소가 없어도 수집은 이어지고, 기록과 음성은 폰에 쌓였다가 연결되면 보낸다.

**특수 권한**(사용자가 직접 켜야 함): 사용 정보 접근, 접근성(화면 내용), 알림 접근, 백그라운드 위치.

> 🔒 **신형 안드로이드/삼성 주의**: 접근성(화면 내용 수집)은 보안 강화로 사이드로드 앱에 하드 차단될 수 있다. 앱 정보 → ⋮ → "제한된 설정 허용"을 거쳐야 하고, 그래도 막히면 그 기기에선 화면 수집만 포기하고 나머지로 쓴다. 접근성에 의존하지 않는 소스가 뼈대다.

### 데스크톱 앱 (Windows · macOS · Linux)

데스크톱 앱이 **서랍을 품는다**: 처음 켤 때 "이 PC에 두기"를 고르면 앱이 서버를 직접 돌린다(기록, 메일·일정 노트, 색인). 폰과 다른 PC는 Tailscale로 이 PC에 보낸다. 트레이에서 비서 화면과 PC 수집기도 돌린다. 자세한 내용은 [desktop/README.md](desktop/README.md).

안드로이드 APK와 같은 [릴리스](https://github.com/jwgung/LoreLog/releases/latest) 페이지에서 받는다(릴리스마다 둘 다 있고, 폰 앱은 지금처럼 APK로 갱신된다):

| OS | 파일 | 설치 |
|---|---|---|
| Windows 10/11 (x64) | `LoreLog_<버전>_x64-setup.exe` | 실행한다. 이 사용자에게만 설치된다(관리자 권한 불필요). Windows 10은 WebView2 런타임이 필요할 수 있다. |
| macOS 11+ (Apple 실리콘·Intel) | `LoreLog_<버전>_universal.dmg` | 열어서 LoreLog를 응용 프로그램으로 끌어 놓는다. |
| Linux (x64) | `LoreLog_<버전>_amd64.AppImage` 또는 `.deb` | AppImage: `chmod +x LoreLog_*.AppImage` 후 실행. deb: `sudo apt install ./LoreLog_*.deb`. |

`life-agent-<버전>-windows-x64.zip`은 Windows용 명령줄 수집기(선택)다. 데스크톱 앱을 쓰면 필요 없다.

**아직 OS 인증서로 서명하지 않았다.** 그래서 처음 켤 때 경고가 뜬다:
- **Windows SmartScreen** "Windows의 PC 보호": **추가 정보 → 실행**.
- **macOS** "LoreLog을(를) 열 수 없습니다" / "Apple에서 확인할 수 없습니다": 한 번 열어 본 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 아래로 내려 LoreLog 옆 **그래도 열기**를 누르고 확인한다. (macOS 15부터는 우클릭 → 열기로 넘어가지 않는다.)
- **Linux**: 경고는 없다. AppImage에 실행 권한(`chmod +x`)만 준다.

**업데이트**: 앱이 켜질 때 새 버전을 확인한다. 있으면 서랍에 "새 버전 X가 있어요 [설치]"가 뜨고, 누를 때만 설치한 뒤 다시 켜진다. 업데이트 파일은 서명돼 있고 앱이 확인한다. Linux는 AppImage에서 동작하고, deb는 새 deb를 설치한다.

## 빌드

```bash
./gradlew :app:assembleDebug      # 디버그 APK
./gradlew :app:assembleRelease    # 릴리스 APK (서명 설정 필요)
```

- 툴체인: AGP 9.4.1(내장 Kotlin), Gradle 9.8.0, compileSdk 37 / targetSdk 36 / minSdk 29, Jetpack Compose.
- 주요 의존성: SQLCipher(net.zetetic), security-crypto, WorkManager, play-services-location, android-vad(Silero/ONNX).
- `local.properties`의 `sdk.dir`로 Android SDK 경로 지정. 릴리스 서명 키스토어·비밀번호는 저장소 밖에 둔다.

**설계 메모** — 폰은 곁에 있어야 생기거나 폰이 공짜 로컬로 주는 것을 잡고(위 소스들), 클라우드에만 있고 인증이 필요한 것(이메일 등)은 서랍 쪽에서 당긴다. 전사·요약처럼 모델이 필요한 처리는 전부 서랍이 사용자가 고른 모델로 한다.

## 법적 주의

한국은 **본인이 참여한 대화** 녹음은 합법이지만, 끼지 않은 남들끼리의 대화 녹음은 불법이다. 통화·대화 녹음의 합법 요건은 나라마다 다르다(일부는 당사자 전원 동의 필요). 기록은 개인용으로만 쓰고, 다른 사람의 데이터를 공개·배포하지 않는다.

## 로드맵

- 신형 기기용 화면 수집 대안(MediaProjection + 온디바이스 OCR) — 접근성 차단 우회.
- 통화·회의 자동 연결의 실기기 검증, 배터리 영향 측정·튜닝.
- 생활 소스 후보: 헬스(걸음·수면), 사진·미디어 메타. 이메일은 폰이 아니라 서랍 쪽에서 당기는 게 맞다.
