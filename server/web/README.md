# server/web — (나중에) 설정·관리자 웹

여기는 **나중에** 만들 **설정·관리자 화면**(로그인, 사용자 관리, 서버 운영)이 들어갈 자리다. 지금은 비어 있다.

비서 화면(대화·할 일·서랍·말하기)은 여기 있지 않다 — 각 앱이 가진다:
- 폰: 네이티브 Compose (`app/`)
- 데스크톱: Tauri 앱에 번들된 화면 (`desktop/shell/ui/`)

`life-ingest`는 이제 **API만** 제공하고 어떤 웹 화면도 서빙하지 않는다(2026-10-29 결정). 설정·관리자 웹을 만들 때 다시 서빙 코드를 붙인다.
